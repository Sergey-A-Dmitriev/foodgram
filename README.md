# Foodgram + API

## Описание проекта

**Foodgram** — REST API для платформы, агрегирующей рецепты различных блюд. Проект позволяет управлять карточками  рецептов. Для понравившихся рецептов можно сформировать список покупок, с ингредиентами. Пользователи могут создавать и редактировать рецепты, с добавлением фотографии рецепта. Добавлять себе в "Избранное" понравившиеся рецепты других авторов. Подписываться на понравившихся авторов и отслеживать появление новых кулинарных шедевров.

## Пользовательские роли

**Аноним:** Неавторизованный пользователь: 
•	Просмотр главной страницы, 
•	просмотр страницы отдельного рецепта,
•	просмотр страницы любого пользователя,
•	доступна и работает форма входа,
•	доступна и работает форма регистрации.

**User:** Авторизованный пользователь: 
•	Доступна главная страница.
•	Доступна страница другого пользователя.
•	Доступна страница отдельного рецепта.
•	Доступна страница «Мои подписки»: 
o	можно подписаться и отписаться на странице рецепта;
o	можно подписаться и отписаться на странице автораю.
•	Доступна страница «Избранное»: 
o	на странице рецепта есть возможность добавить рецепт в список избранного и удалить его оттуда;
o	на любой странице со списком рецептов есть возможность добавить рецепт в список избранного и удалить его оттуда.
•	Доступна страница «Список покупок»: 
o	на странице рецепта есть возможность добавить рецепт в список покупок и удалить его оттуда;
o	на любой странице со списком рецептов есть возможность добавить рецепт в список покупок и удалить его оттуда;
o	есть возможность выгрузить файл с перечнем и количеством необходимых ингредиентов для рецептов из «Списка покупок»;
•	Доступна страница «Создать рецепт»: 
o	есть возможность опубликовать свой рецепт;
o	есть возможность отредактировать или удалить свой рецепт.
•	Доступна возможность изменить пароль.
•	Доступна возможность изменить/удалить изображение профиля.
•	Доступна возможность выйти из системы.

**Admin:** Полный контроль, включая управление проектом, а также назначение ролей другим пользователям.

**Superuser Django:** Все права admin + технические права Django.

## Endpoints

### Auth

| Endpoint                            | Метод  | Описание                               | Права доступа               |
|-------------------------------------|--------|----------------------------------------|-----------------------------|
| `/api/users/`                       | POST   | Создание пользователя                  | Доступно без токена         |
| `/api/auth/token/login/`            | POST   | Login, возвращает токен аутентификации | Доступно без токена         |
| `/api/auth/token/logout/`           | POST   | Logout, выход из системы               | Авторизованный пользователь |
| `/api/users/set_password/`          | POST   | Изменение пароля                       | Авторизованный пользователь |

### Users

| Endpoint                    | Метод  | Описание                               | Права доступа               |
|-----------------------------|--------|----------------------------------------|-----------------------------|
| `/api/users/`               | GET    | Получение списка всех пользователей    | Доступно без токена         |
| `/api/users/{id}/`          | GET    | Получение страницы пользователя        | Доступно без токена         |
| `/api/users/{id}/subscribe/`| POST   | Создание подписки                      | Авторизованный пользователь |
| `/api/users/{id}/subscribe/`| DELETE | Удаление подписки                      | Авторизованный пользователь |
| `/api/users/me/`            | GET    | Получение данных своего профиля        | Авторизованный пользователь |
| `/api/users/me/avatar/`     | PUT    | Добавление аватара в профиль           | Авторизованный пользователь |
| `/api/users/me/avatar/`     | DELETE | Удаление аватара из профиля            | Авторизованный пользователь |
| `/api/users/subscription/`  | GET    | Получение списка подписок              | Авторизованный пользователь |

## Локальное развертывание

**Клонирование репозитория:**

```bash

git clone https://github.com/Sergey-A-Dmitriev/foodgram.git
cd <название_директории_проекта>
```

**Создание и активация виртуального окружения:**

```bash

python -m venv venv

source venv/bin/activate  # Для Linux/macOS

source venv/Scripts/activate    # Для Windows
```

**Установка зависимостей:**

```bash

pip install -r requirements.txt
```

**Подготовка базы данных:**

```bash

python manage.py migrate
```

**Создание суперпользователя (опционально):**

```bash
python manage.py createsuperuser
```

**Запуск сервера:**

```bash

python manage.py runserver
```

Сервер будет доступен по адресу `http://127.0.0.1:8000/.`

## Примеры использования API

### Создание пользователя
```
POST /api/users/
{
    "email": "john_doe@example.ru",
    "username": "john_doe",
    "password": "securePass123"
}
```
Ответ:

```
{}JSON
{
  "id": 9,
  "email": "john_doe@example.ru"
  "username": "john_doe"
  "first_name": "",
  "last_name": ""
}
```

### Регистрация пользователя
```
POST /api/auth/token/login/
{
    "email": "john_doe@example.ru",
    "password": "securePass123"
}
```
Ответ:

```
{}JSON
{
    "auth_token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b"
}
```
