# Foodgram + API

## Описание проекта

**Foodgram** — REST API для платформы, агрегирующей рецепты различных блюд. Проект позволяет управлять карточками  рецептов. Для понравившихся рецептов можно сформировать список покупок, с продуктами. Пользователи могут создавать и редактировать рецепты, с добавлением фотографии рецепта. Добавлять себе в "Избранное" понравившиеся рецепты других авторов. Подписываться на понравившихся авторов и отслеживать появление новых кулинарных шедевров.

## Пользовательские роли

**Аноним:** Неавторизованный пользователь:
  * просмотр главной страницы,
  * просмотр страницы отдельного рецепта,
  * просмотр страницы любого пользователя,
  * доступна и работает форма входа,
  * доступна и работает форма регистрации.

**User:** Авторизованный пользователь:
  * просмотр главная страница.
  * просмотр страницы другого пользователя.
  * просмотр страницы отдельного рецепта.
  * просмотр страницы «Мои подписки»:
      * можно подписаться и отписаться на странице рецепта;
      * можно подписаться и отписаться на странице автораю.
  * доступна страница «Избранное»: 
      * на странице рецепта есть возможность добавить рецепт в список избранного и удалить его оттуда;
      * на любой странице со списком рецептов есть возможность добавить рецепт в список избранного и удалить его оттуда.
  * доступна страница «Список покупок»: 
      * на странице рецепта есть возможность добавить рецепт в список покупок и удалить его оттуда;
      * на любой странице со списком рецептов есть возможность добавить рецепт в список покупок и удалить его оттуда;
      * есть возможность выгрузить файл с перечнем и количеством необходимых продуктов для рецептов из «Списка покупок»;
  * доступна страница «Создать рецепт»: 
      * есть возможность опубликовать свой рецепт;
      * есть возможность отредактировать или удалить свой рецепт.
  * доступна возможность изменить пароль.
  * доступна возможность изменить/удалить изображение профиля.
  * доступна возможность выйти из системы.

**Admin:** Полный контроль, включая управление проектом, а также назначение ролей другим пользователям.

**Superuser Django:** Все права admin + технические права Django.

## Локальное развертывание

**Клонирование репозитория:**

```bash

git clone https://github.com/Sergey-A-Dmitriev/foodgram.git
cd foodgram
```

**Создание и активация виртуального окружения:**

```bash

python -m venv venv

source venv/bin/activate  # Для Linux/macOS

source venv/Scripts/activate    # Для Windows
```

**Установка зависимостей:**

```bash

pip install -r requirements.txt
```

**Подготовка базы данных:**

```bash

python manage.py migrate
```

**Создание суперпользователя (опционально):**

```bash
python manage.py createsuperuser
```

**Загрузка основных справочников (продукты и теги):**

```bash
python manage.py load_ingedients
python manage.py load_tags
```

**Запуск сервера:**

```bash

python manage.py runserver
```

Сервер будет доступен по адресу  
[локальный сервер](http://127.0.0.1:8000/)
